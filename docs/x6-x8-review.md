# X6–X8 local review · 2026-09-22

## Delivery scope

At the end of the local review, all eight games were available locally (nine campaigns including both X4 characters), while the public deployment remained X1–X4. The user subsequently authorized publishing this expansion and refreshing the desktop collection shortcut.

- X6: 20 field pickups (8 hearts, 2 Sub Tanks, Weapon Tank, EX Tank, 8 armor programs), Blade-first roadmap, early Zero rescue, Shadow cleanup, permanent Reploid loss, personal upgrade ownership, key part carriers, fortress and ordinary refill tips. The completionist checklist covers 128 rescues; individual directions for all 128 are linked externally, while key equipment carriers are described in the guide.
- X7: 16 field pickups (8 hearts, 2 Sub Tanks, Weapon Tank, EX Tank, 4 Glide parts), all 16 chip-bearing Reploids, X's rescue unlock, character ownership and New Game+ limits, weaknesses for X/Axl and Zero, ordinary recovery tips.
- X8: 28 field locations (8 capsules + 20 Rare Metals), Normal/Hard warning, all hunter teams/loadouts, both Troia score rewards, generator access, development costs versus field collection, White Axl and other New Game+ unlocks. Noah's Park is an additional stage, not a ninth Maverick; Dynasty correctly has no field pickups.

## Shared layout

220px is now the maximum screenshot height for every stage and return grid containing 3+ items. Smaller widths may reduce actual height. Full images remain contained, with native-resolution enlargement and Escape/Close dismissal. One/two-item sizing is unchanged. Long four-item instructions still require vertical scrolling; no text or scene is clipped to force a one-screen fit.

The template now indexes and credits optional side stages. Rare Metal index entries include the item name so several rewards in one stage remain distinguishable. Collection and game menus include X1–X8. The optional local size experiment now defaults to 220px and supports all eight games; normal builds exclude its panel.

## Sources and media

Each guide links its gameplay references and per-image contributor/source records. RetroPixel/Mega Man XZ directions were cross-checked with independent GameFAQs authors, MMHP, MMKB and targeted reference guides. Game mechanics were not inferred from earlier entries.

All 64 pickup-image entries were visually reviewed in contact sheets. X6 uses full 320×240 scenes; X7/X8 generally use full 1199×900 scenes. Two ambiguously named X8 Life Tank files were remapped after visual inspection: the generator room belongs to Pitch Black and the score-prize room to Troia Base. X6 Mijinion's Heart and Blade Arms share the capsule-area scene; the heart may already be collected in that capture. Source characters/suits identify locations and need not match the proposed route.

X7/X8 high-resolution PNGs were converted losslessly to WebP, preserving pixel dimensions and complete scenes. Combined size fell from 37,744,952 to 28,851,636 bytes. Images load lazily and all credits remain at the bottom. No video audio was played.
